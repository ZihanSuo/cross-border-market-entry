## 为什么不再重跑（冻结决策）

技术上可以重跑一次拿到完整审计日志，但**期望收益是负的**，依据是本项目自己的数据：

| 版本 | 配置 | 严重问题 |
|---|---|---|
| 东边野兽 v6 | research_qa | 0 |
| 东边野兽 v7 | **同配置、同 prompt，仅重跑一次** | 3 |

**同配置重跑会变差，这在本项目里发生过不止一次。** v4 当前是 0 严重问题
（37 个 URL / 4 份产出），重跑有相当概率得到更差的结果，届时要么用更差的版本，
要么解释为什么最终版不是最新版——两种都不划算。

因此：**v4 冻结为花知晓案例的最终展示版本，审计缺口如实记录在案。**
明确记账一个已知缺口，比重跑去赌一个更好的结果更符合这个项目的一贯做法。
