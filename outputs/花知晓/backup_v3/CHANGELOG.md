### 工程改动（本版背后）

1. 新任务 `evidence_gap_fill_task`：可行性输出「证据缺口清单」→ 二轮只补缺口  
2. **锁证据质量、不锁检索剧本**：禁止假 URL；引用须抽出可核对事实；query 自定  
3. `research_depth_check.py` + 跑完自动打印；可选 `--strict-depth`  
4. 可行性 `max_iter: 25`；补证两角度规则（态度向 + 零售/品牌渠道向）

## 还差什么（进全链路时盯紧）

1. 补证仍偏薄：KONVY「25 家门店」等断言挂 Facebook，级别标 A 偏乐观——开拓勿当硬事实  
2. 可行性风险表述仍易把「态度待验证」写成「若存有偏见」；合规有时抬得过高  
3. 门槛表偶发「待确认」占位；90 天动作仍偏问卷  
4. **本目录没有** `market_expansion.md` / `competitor_battlecard.md`——全链路跑完应另存 `backup_v4`（或 `v3_full`），不要覆盖本深度试点

## 面试怎么一句话讲

> 发现可信度规则变严后深度仍上不去，根因是可行性零搜索就下结论、补证不换零售角度。于是加了缺口二轮补证，并用 tool_audit 做深度门禁；花知晓泰国试点上可行性从 0 次搜索到 5 次，门禁清零，才放开全链路。
