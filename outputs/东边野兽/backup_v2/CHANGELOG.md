# backup_v2 提升日志（相对 backup_v1）

- **Case**：东边野兽 / Herbeast → 英国
- **v1 时间**：约第一轮跑通（引用纪律收紧前）
- **v2 时间**：启用 Serper + 收紧 `source_rules` + 加入 `knowledge/markets/uk.md` 后重跑
- **对比文件**：本目录三份 md vs `../backup_v1/` 同名文件

---

## 一句话

v2 从「像作文、易编造」进到「有链接的研究初稿」；**还没到决策备忘录水平**（那是下一轮 v3 的目标）。

---

## 相对 v1：明确变好了什么

| 维度 | v1 | v2 | 评价 |
|------|----|----|------|
| **引用格式** | `source: Mintel` / `UK Government` / `Statista`（无链接） | 多数结论带 `https://`；文末有参考文献列表 | ✅ 大提升 |
| **假语录** | 伪造 Reddit 用户原话 | 改为「未找到具体用户讨论」 | ✅ 大提升 |
| **市场规模** | 几乎无数字 | 出现 Clean Beauty 营收/份额数字 + URL | ✅ 提升（来源质量仍一般） |
| **监管** | 空泛提 UK REACH | 出现 Responsible Person / 通知链接、gov.uk / CTPA | ✅ 提升 |
| **搜索** | 像先验知识 | 能看出用了检索结果 | ✅ 提升 |
| **竞品来源** | 偏弱 / 混入开拓路径 | 各家有官网链接；**不再夹「推荐进入路径」专章** | ✅ 结构提升 |
| **开拓路径** | 空引用 | 有 Cult Beauty 等链接 | ⚠️ 半提升（见下） |

---

## 相对 v1：仍然不够 / 甚至仍像玩具的点

| 问题 | 说明 |
|------|------|
| **结构仍是「填空作文」** | 仍是理解摘要→概览→趋势…，不是「一页建议 + 门槛」 |
| **brief 品牌事实用得少** | 创始人/JOYCE/灵芝等具体资产仍很少出现 |
| **用户洞察仍在推测** | 承认没找到讨论后，又写「更乐于尝试中国草本」 |
| **置信度注水** | 如开拓里用 Cult Beauty **首页** 支撑「平台入驻置信度：高」 |
| **竞品无 SKU 标价** | 仍写「中高端」，对比表无 £ 与商品页 |
| **二手/付费摘要页** | Grand View / 博客类链接可点，但不等于咨询级一手证据 |

## 各文件对照（精简）

### `market_feasibility.md`
- ✅ 有市场规模数字 + URL；监管更具体
- ✅ 去掉假 Reddit 语录
- ❌ 结论仍是软的「有条件进入」
- ❌ 用户段仍含无据推测

### `market_expansion.md`

- ❌ 「高」置信度依据偏弱（首页 ≠ 可入驻证据）

### `competitor_battlecard.md`
- ✅ 不再串开拓路径章节；官网 URL 齐全
- ❌ 无具体 SKU/标价；差异化仍偏口号

## 对应改动了什么配置（方便你回忆）

v1 → v2 之间主要工程改动：

1. `.env` 启用 `SERPER_API_KEY`
2. `knowledge/core/source_rules.md` 收紧（禁空引用、禁假语录）
3. 新增 `knowledge/markets/uk.md` + `registry.yaml` 英国映射
4. feasibility / competitor / expansion task 硬规则同步收紧

> **注意**：决策备忘录结构、SKU 强制标价等（「三刀」）是在 **备份 v2 之后** 才改的配置；那一轮应存成 **`backup_v3`**，不要覆盖 v2。

## 面试怎么一句话讲 v1→v2

> 第一轮输出像通用作文还带假引用；我收紧来源规则、接上搜索和英国知识包后，第二轮变成带 URL 的可追溯初稿，假语录消失、监管与市场规模可点击核对——但结构仍偏模板，所以继续改成决策备忘录和 SKU 级竞品表。
