# 泰国市场包（彩妆 / T-beauty 赛道出海）

供 `market_scope` 含泰国 / Thailand / TH 时加载。以下为研究锚点与检索方向，**具体数字仍须检索后附 URL**；无 URL 不写死数字。跟 uk.md 的定位不同：这里默认品类是彩妆（非护肤），且目标市场的本土品牌（T-beauty）本身就是全球增长故事，竞争参照系不能直接套用英国那套天然护肤逻辑。

## 监管与合规（优先检索）

- 化妆品监管主体：Thai FDA（อย.，泰国食品药品监督管理局），采用**通知制（notification）而非事前审批制**——产品上市前需完成通知备案，而不是像药品那样等审批通过
- 区域协调框架：ASEAN Cosmetic Directive（东盟化妆品指令）——泰国的成分限制/禁用物质清单以此为基础，检索时可同时查 ASEAN 层面的更新（如禁用/限用物质增补）
- 进口要求：境外企业通常需要**在泰国本地设立公司或委任泰国本地代理（Local Responsible Person / 代理商）**才能完成通知备案，不能以境外主体直接申报——这条与英国的 Responsible Person 逻辑类似，但泰国这边更强调"必须有本地注册实体或代理"
- 通知有效期：公开资料显示为 3 年，到期需重新申报（检索时核实是否有更新）
- 宣称合规：避免医疗化宣称（如"祛斑""治疗"类词汇通常需要更高层级的审批，普通彩妆/护肤宣称应避开）
- 输出时：每条监管结论附官方或专业法规机构（Thai FDA 官网、ASEAN 官方文件、CIRS/REACH24H 等合规服务商的解读页）链接；不确定标「需本地合规复核」，行业标配合规步骤（备案、代理）不当品牌特有否决理由

## 渠道结构（战略层，非执行排期）

常见触达类型（按品类验证，勿默认全适用）：

- **电商平台**：Shopee、Lazada、TikTok Shop 是泰国最主流的三个平台；公开报道普遍认为 Shopee 和 TikTok Shop 份额领先、Lazada 其次，**具体份额数字检索后再写，不要不带 URL 就下结论**
- **美妆垂直零售/集合店**：如 KONVY、Beautrium、Sephora Thailand、Watsons、Boots Thailand 等——检索目标品牌是否在这些平台/门店有商品页或门店信息，是判断"是否已有零售触点"的关键证据
- **线下渠道仍重要**：公开报道提到泰国美妆消费中线下门店（含便利店）的到店频次显著高于线上转化率，不能默认"东南亚=纯电商"
- **内容驱动**：达人（influencer）带货和"抢购式"内容（haul 视频）是泰国美妆渠道的重要组成部分，与英国编辑型集合店逻辑（如 Cult Beauty）不同，泰国更偏内容电商/直播

## 竞争参照（L1 名单提示，非最终结论——注意：泰国本土彩妆是全球增长故事，不是弱势竞品）

- **T-beauty（泰国本土彩妆）头部品牌**：Mistine（公开报道中常被列为市场领导者）、Cathy Doll（2012年上市，公开报道称已进入30+市场，主要在亚太）、Srichand、4U2、Sivanna、Browit、Oriental Princess、Cute Press 等
- **重要提醒**：这些不是"等着被教育的本土弱势品牌"——公开报道的叙事是"T-beauty 正在挑战 K-beauty 的全球地位"，分析中国彩妆品牌进入泰国时，必须把本土品牌当成真实竞争对手看待，不能默认"外国品牌自带光环"
- **K-beauty** 在泰国彩妆市场也是重要参照系，中国品牌进入时常被拿来跟 K-beauty 而非本土西方品牌对比定位
- 最终竞品名单以检索 + 用户 brief 为准；找竞品代表 SKU 时，认准电商平台的**单品详情页**，不要用品牌首页或分类页充数（同 `competitor_analysis.yaml` 硬规则 4）

## 文化与信任（桌面研究 vs 人工调研）

**Agent 应先做桌面研究，不要整段写「文化接受度待调研」：**

- **品类层（优先）**：中国彩妆/K-pop 美学相关风格（如公开报道提到的 Rococo、maximalism、fairytale 视觉）在泰国 Gen Z 消费者中的可见度——检索该品类在 Shopee/TikTok Shop/KONVY 等平台是否有同类型商品可对标
- **叙事层（分开写）**：「中国品牌」在泰国的公开报道或讨论态度；无 URL 则「证据不足」，禁止写成已证实偏见或已证实欢迎——市场层面的开放度不能直接推导成对某个具体品牌的态度
- 信任线索类型：达人合作、社媒声量、零售在售、可核实评价、是否有本地化包装/语言
- 敏感点：文化挪用式叙事、对泰国本土审美的刻板化描述——标 HITL
- **问卷/焦点小组**：不在 Agent 职责内；仅可列为人工后续

## 检索建议（Agent 应主动搜索）

1. `Thailand cosmetic notification Thai FDA ASEAN Cosmetic Directive`（监管）
2. `Thailand color cosmetics market size` + 年份（须具体报告/文章页 URL，禁止仅平台首页）
3. 目标竞品/目标品牌是否在 `KONVY` / `Beautrium Thailand` / `Shopee Thailand` / `Lazada Thailand` / `TikTok Shop Thailand` 有**商品页**
4. `Mistine` / `Cathy Doll` / `Srichand` 等本土品牌的市场地位、代表 SKU、标价（检索单品页，不用首页）
5. `Chinese beauty brand Thailand` / `C-beauty Thailand` / `Chinese makeup brand Southeast Asia`（仅有链接的报道；找不到就写检索无果）
6. 目标品牌自身是否已在泰国有零售/达人合作公开报道（区分「已有零售触点」vs「仅品牌自称计划进入」，不能混为一谈）
