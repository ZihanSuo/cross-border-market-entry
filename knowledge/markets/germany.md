# 德国市场包（家电 / 智能硬件出海）

供 `market_scope` 含德国 / Germany / DE 时加载。以下为研究锚点与检索方向，**具体数字仍须检索后附 URL**；无 URL 不写死数字。

**与 uk.md / thailand.md 的定位差异**：那两份是美妆护肤赛道，核心是「成分/品类接受度」；本包针对**家电与智能硬件**，核心是**参数、能效、认证与第三方测评**。美妆那套「成分透明」「品类文化接受度」在这里基本不适用，不要照搬。

## 监管与合规（优先检索）

家电与美妆的合规逻辑完全不同，**不要套用「备案 + 本地责任人」那套**：

> **欧盟层面的通用制度（CE、EU 能效标签、GPSR、REACH/CLP、GDPR）见 `markets/eu_common.md`**，
> 该包会与本包一起加载。以下只列**德国特有**的部分，避免同一份内容维护两遍。

- **WEEE / 电子废弃物**：德国要求生产者在 `stiftung-ear` 注册并承担回收责任；未注册不得销售
  （WEEE 是欧盟指令，但**注册义务逐国落地**，德国的落地机构就是 stiftung-ear）
- **包装法（VerpackG）**：需在 LUCID 包装登记册注册（德国对欧盟包装 EPR 的落地）
- **产品安全**：**GS 标志**（Geprüfte Sicherheit）——非强制，但德国市场认可度高，
  这是德国相对其他欧盟国家的显著差异点
- **EU 能效标签在德国的特殊权重**：它在多数欧盟国家是合规要求，但**在德国同时是核心销售论据**，
  能效等级直接进入消费者比价决策，不能只当成合规项处理
- 输出时：每条监管结论附官方来源（EU 官方、`stiftung-ear.de`、`bmuv.de` 等）；不确定标「需本地合规复核」。这些都是**行业标配**，不当品牌特有否决理由

## 渠道结构（战略层，非执行排期）

- **Amazon.de**：德国智能家电最主要的线上战场，且**商品页有稳定的 URL 结构与公开标价**，是取证的首选
- **专业电商**：MediaMarkt、Saturn（同属一家）、Otto、Cyberport、Notebooksbilliger
- **线下**：MediaMarkt/Saturn 门店，以及 Expert、Euronics 等联合采购组织
- **品牌 DTC**：`roborock.de` 这类本地站
- 德国消费者对**线下体验 + 线上比价**的组合依赖度高，`idealo.de`、`geizhals.de` 这类比价站是重要的价格发现渠道，也是查历史价格的好来源

## 竞争参照（L1 名单提示，非最终结论）

**按品类分，不要混为一谈：**

- **扫地机器人 / 清洁电器**：Roborock、Dreame（追觅）、Ecovacs（科沃斯）、iRobot、Dyson、Vorwerk（德国本土，Kobold 系列）
- **白色家电（洗衣机 / 洗烘一体）**：**Bosch、Siemens（同属 BSH 集团）、Miele、AEG、Beko、LG、Samsung**——前三家是德国本土品牌，在德国家电市场有极强的品牌信任与渠道积累，**中国品牌进这个品类面对的是完全不同的竞争格局**
- 提醒：一个品牌在某品类领先，**不代表在另一品类有任何优势**。跨品类时必须重新做竞争分析，不能复用原品类的市占率数据

## 第三方测评（德国市场的特殊性，务必重视）

德国有一套影响力极强的独立测评体系，**它在德国消费者决策中的权重远高于社媒口碑**：

- **Stiftung Warentest**（`test.de`）：德国最权威的独立消费品测评机构，其评分对销量影响显著。付费墙内容较多，但结论摘要通常公开
- **ÖKO-TEST**：侧重环保与健康维度
- **Computer Bild / CHIP / Notebookcheck**：科技类产品测评
- **检索建议**：优先找这些机构的具体测评页面，而不是社媒讨论。**在德国市场，「Stiftung Warentest 给了什么评级」比「Instagram 上有人夸」有价值得多**

## 文化与信任（桌面研究 vs 人工调研）

**Agent 应先做桌面研究，不要整段写「文化接受度待调研」：**

- **产品层（优先）**：目标品类在德国的价格带、能效等级分布、主流参数区间——这些在 Amazon.de 与比价站上都能查到具体页面
- **品牌信任层（分开写）**：德国消费者对「中国家电品牌」的公开报道或测评评价；无 URL 则「证据不足」，**禁止**写成已证实偏见或已证实欢迎
- 德国市场对**数据隐私**敏感度高（GDPR 原生市场），带摄像头/联网的智能家居产品需关注隐私相关的公开讨论与合规表述
- **问卷/焦点小组**：不在 Agent 职责内；仅可列为人工后续

## 检索建议（Agent 应主动搜索）

1. `CE marking [品类] requirements` / `EU energy label washing machine`（监管）
2. `stiftung-ear WEEE registration Germany`（回收注册）
3. 目标品牌或竞品在 `Amazon.de` 的**具体商品页**（有标价、有型号，取证首选）
4. `Stiftung Warentest [品类]` / `test.de [品类]`（第三方测评评级）
5. `idealo.de [型号]`（价格历史与比价，可交叉验证标价）
6. `[品类] Marktanteil Deutschland` + 年份（市场份额，须具体报告页）
7. 若品牌已在该市场经营某品类：分别检索**原品类**与**新品类**的竞争格局，不要混用
