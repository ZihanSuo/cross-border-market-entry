# 英国市场包（Clean Beauty / 护肤出海）

供 `market_scope` 含英国 / UK / Britain 时加载。以下为研究锚点与检索方向，**具体数字仍须检索后附 URL**；无 URL 不写死数字。

## 监管与合规（优先检索）

- 化妆品监管：英国脱欧后体系（常检索关键词：OPSS、UK Cosmetics Regulation、Responsible Person）
- 化学品：UK REACH（成分注册/限制可能与 EU REACH 不同）
- 宣称合规：避免医疗化宣称；成分与标签英文合规
- 进口：需确认是否需本地责任人（Responsible Person）、标签语言、通知/登记要求
- 输出时：每条监管结论附 gov.uk 或官方 PDF 链接；不确定标「需本地合规复核」

## 渠道结构（战略层，非执行排期）

常见触达类型（按品类验证，勿默认全适用）：

- 美妆编辑电商 / 集合店型平台（如 Cult Beauty、Space NK 等——是否适合本品牌需检索核实）
- 百货 / 丝芙兰等零售（入驻门槛与定位匹配度需验证）
- DTC 独立站 + 本土支付与物流
- 药房 / 有机零售渠道（天然/草本定位时更相关）

## 支付与履约

- 消费者习惯：卡支付、PayPal、Apple Pay 等常见；以检索结果为准
- 跨境：关税/VAT、退货期望较高；履约时效影响复购与评价
- 输出时：只写定性结论 + 来源；不写具体费率除非有 URL

## 文化与信任（桌面研究 vs 人工调研）

**Agent 应先做桌面研究，不要整段写「文化接受度待调研」：**

- **品类层（优先）**：herbal / botanical / natural / clean beauty、菌菇·灵芝等成分在英国零售是否可见；Weleda、Neal's Yard 等标杆是否成立
- **叙事层（分开写）**：「中国品牌 / 东方草本」公开报道或讨论；无 URL 则「证据不足」，禁止写成已证实偏见
- 信任线索类型：成分透明、认证、编辑推荐、零售在售、可核实评价
- 敏感点：夸大功效、漂绿、文化挪用式叙事——标 HITL
- **问卷/焦点小组**：不在 Agent 职责内；仅可列为人工后续

## 竞争参照（L1 名单提示，非最终结论）

天然/草本/Clean 赛道常见对标类型：Aesop、Weleda、Neal's Yard Remedies、Pai 等；最终名单以检索 + 用户 brief 为准。
