# TikTok 内容与投流规则（项目内置知识包，海外渠道）

> 用于「出海」内容拓展方向（未来拓展方向，V1 未启用）。对标国内的 `douyin_performance_rules.md`，
> 但 TikTok 面向的是**目标市场当地用户**（如英国），不是境内用户，算法机制、合规要求、
> 用户文化都不一样，不能直接照搬抖音的规则。市场特定的合规细节（如英国 ASA）以
> `knowledge/markets/*.md` 检索结果为准，本文件只提供跨市场通用的平台规则。

## 内容侧

- **黄金 3 秒（严格于抖音的"3 秒钩子"）**：算法在约 1.5 秒就开始做初步分发判断，用户平均 1.7 秒决定划走与否；钩子要素是「意外感 + 相关性 + 明确的价值点」，不是单纯喊品牌名。
- **完播率门槛在提高**：2025 年下半年起，获得大规模分发的完播率基准已上移到约 70%（几年前还只需要约 50%），意味着内容要更短、更聚焦，而不是塞更多信息。
- **时长建议**：15-30 秒适合快钩子/追热点；30-60 秒是大多数品牌内容的甜蜜点；60-180 秒仅适合能全程留住用户的教程类内容。
- **粉丝量不是分发前提**：TikTok 的推荐机制不看粉丝数，新账号也可能因为匹配到对的社群而获得大量曝光——对新出海品牌是利好，但也意味着"素材质量"比"账号权重"更重要。
- **内容类型**：实用教程、有观点的"争议性"表达、反差/前后对比、轻幽默类内容分享率更高；泛泛的品牌宣传片表现通常较差。
- **钩子模板复用，正文可以不变**：不用每条视频都重新设计开头，维护 4-6 个钩子模板轮换测试即可。

## 投流侧（战略层，非具体出价/预算数字）

- 沿用"小预算测试 -> 优胜素材放量"的迭代逻辑（与抖音规则一致），但 TikTok 广告后台的受众定向逻辑、素材审核标准是独立体系，不能假设跟抖音巨量引擎通用。
- 人群定向建议只能基于 brief/市场研究里已有的目标受众描述，不得凭空给出比输入信息更精确的定向结论。
- 预算给区间和前提假设，不给具体数字（除非 brief 里明确提供预算）。

## 合规与披露（硬规则，跨市场通用底线）

1. **品牌付费/赠品/合作内容必须显式披露**：2025 年 8-9 月起 TikTok 强制执行"Disclose commercial content"开关，不开会被限流甚至下架；开启后会显示「Paid Partnership」标签。
2. **披露必须"看得见"，不能只藏在文案或话题标签里**：仅写 `#ad`/`#collab` 在描述区不够，需要在视频内明显位置披露（具体到某个市场时，参照当地广告监管机构规则，如英国 ASA/CAP Code 要求披露必须在用户互动前就能识别）。
3. 具体某个目标市场的广告披露细则（比如英国要求标"Ad"且必须在参与前可见、CMA 对隐藏广告最高可处全球营业额 10% 罚款）以该市场的 `knowledge/markets/*.md` 或检索结果为准；本文件不假设某一国规则适用于所有市场。

## 风险提示

- 禁止"保证爆款""必涨粉""100% 转化"等绝对化承诺。
- 数据/效果类结论必须可追溯，无法核验时标"待验证"，不得编造案例数据。
- 品牌方是中国公司这件事本身不是风险也不是卖点，不要预设"东方叙事"在 TikTok 一定吃香或一定被排斥——参考 `knowledge/markets/*.md` 里"品类接受度 vs 品牌叙事接受度需分开写"的原则，此处同样适用。

## 已知空白（尚未研究，别当已完成）

- 未针对具体品类（如美妆护肤）做过 TikTok Shop / 直播电商在英国等市场的可行性调研。
- 未研究不同目标市场（英国 vs 东南亚）之间 TikTok 用户习惯、创作者生态的差异，目前只写了跨市场通用规则。
